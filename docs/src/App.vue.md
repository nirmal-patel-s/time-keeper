# App Component

## Overview
This is the root Vue component for the Time Keeper application. It serves as the main container for all other components.

## Dependencies
- Vue.js (defineComponent)
- PrimeVue Button component

## Structure
The component is structured with:
- TypeScript script section with component definition
- Template section with centered layout using flex classes
- Style section (currently empty)

## Functionality
The App component:
- Displays a PrimeVue Button with "Verify" label
- Uses flexbox for horizontal centering

## Usage
This component is the main entry point for the UI and is mounted by the Vue application instance in main.ts.
