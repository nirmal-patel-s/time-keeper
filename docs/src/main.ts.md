# Main Application Entry Point

## Overview
This file serves as the main entry point for the Time Keeper application. It initializes the Vue application and configures PrimeVue with the Aura theme preset.

## Dependencies
- Vue.js
- PrimeVue
- Aura theme from @primeuix/theme

## Key Functionality
- Creates the Vue application instance
- Configures PrimeVue with the Aura theme preset
- Mounts the application to the DOM
